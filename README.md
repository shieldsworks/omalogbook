# Omalogbook

The ship's log for [Omahoy](https://github.com/shieldsworks/omahoy).

**Status: planned.** Nothing to install yet.

## What it will do

- Write entries automatically: position, course, speed and pressure, hourly and
  at events like departing or anchoring.
- Keep your own notes alongside the automatic entries.
- Store everything as plain text in a git repo you own, and push whenever there's
  a connection.
